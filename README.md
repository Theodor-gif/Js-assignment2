# JavaScript — Assignment 2

This project is the final assignment for the Mayerfeld Practicum Program® — Frontend Developer.

In this web application the user can play one of two games — Rock-paper-scissors or the Jumping game — or use the calculator to perform a calculation on two numbers.

## Features

- **Home page**
  - Choose between the two games or the calculator
- **Calculator**
  - Add, subtract, multiply and divide two numbers
- **Rock-paper-scissors**
  - The player plays against the computer
  - Each round, the player picks rock, paper or scissors
  - The goal is to beat the computer
- **Jumping game**
  - The player can enter a player name
  - The player has to jump and avoid as many obstacles as possible
  - The goal is to get the highest score

## How to Use

### Calculator

- Click the buttons with the mouse
- Tap the buttons on mobile
- Or type the numbers and operators with the keyboard

### Rock-paper-scissors

- Click your choice: rock, paper or scissors
- Tap your choice on mobile

### Jumping game

- Type a player name to start
- Press [key] to jump
- Tap the screen to jump on mobile

## Tech Stack

- HTML5
- CSS
- Vanilla JavaScript
